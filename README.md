# ASICWRU

ASICWRU is Case Western Reserve University’s student group focused on ASIC design and chip development.

Our website showcases the group’s projects, resources, and activities, with a focus on taking digital hardware designs from RTL all the way to physical silicon using open-source EDA tools and Tiny Tapeout.

The site includes information about:

- ASICWRU and its mission
- Current and past chip design projects
- Learning resources for ASIC and digital design
- Tapeout information and results
- Alumni and group involvement
- Ways to get involved with the organization

One of the group’s first projects was a single-cycle RISC-V processor fabricated through the IHP 130nm process.

## Website

The website is built primarily with HTML, CSS, and JavaScript and serves as the main public-facing site for ASICWRU.

## About ASICWRU

ASICWRU is part of the CWRU Chips / ASIC Design community at Case Western Reserve University, giving students hands-on experience with the full digital chip design flow from RTL to GDS and ultimately real silicon.
